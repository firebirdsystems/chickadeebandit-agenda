# Agenda

A [Chickadee Bandit](https://chickadeebandit.com/app-library/agenda) app.

Run structured meetings for your household or organization. Collect agenda items, track action items, and capture notes.

## Features

- Collect agenda items from members before the meeting.
- Capture notes per item.
- Track action items to completion.
- Works for households and organizations.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-agenda/releases/latest/download/bundle.json
```
